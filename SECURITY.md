# Security and privacy

## Report a problem

Please do not open a public issue for a vulnerability, exposed credential, or
private photograph. Use GitHub's private vulnerability reporting for
`prichardsondev/no-dark-nights` when available, or contact the repository owner
privately through the GitHub profile.

Include the affected page or file, what you observed, and the smallest safe
steps needed to reproduce it. Do not attach someone else's private image.

## Privacy model

- Source photos are decoded and processed in the browser.
- The studio does not upload source photos to a No Dark Nights server.
- STL generation happens on the device.
- A source photograph must not be attached to Codex. The learner or supervising
  adult checks it visually inside the Studio.
- The application does not intentionally collect children’s contact
  information.
- Gallery photographs are separate published assets shown only with permission.
- A public deployment may still receive ordinary hosting request metadata such
  as an IP address and browser headers, and hosting/security providers may set
  necessary security cookies.
- External services have their own privacy policies.

## Safe classroom use

- Use neutral or permission-cleared images for lessons and tests.
- Contact is disabled for learner sites. Only an adult site manager may later
  configure an adult-controlled contact method.
- Do not include names, school details, addresses, or location metadata.
- Use a private Sites review before making a student project public.
- Ask a trusted adult to review publishing, purchases, electrical hardware,
  and printer operation.

## Supported version

Security and privacy fixes target the latest commit on the default branch.
