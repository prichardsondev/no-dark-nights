# Local Sites configuration

`hosting.json` identifies one owner's Sites project. It is intentionally
ignored by Git and must never be committed or copied into a learner's project.

When an adult approves a private deployment, Sites may create this local file
for that learner, family, school, or organization. Before any version is saved
or deployed, confirm the resolved site name, address, owner, and access level.
Never use the original No Dark Nights project for a learner copy.
