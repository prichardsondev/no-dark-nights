# Example image and STL policy

Examples must be safe to redistribute and useful for learning.

## Allowed

- simple gradients, geometric patterns, and generated test charts;
- original illustrations whose creator agreed to the MIT License;
- public-domain images with the source and status documented;
- STL files generated from an allowed example image.

## Not allowed

- personal family, child, school, medical, or location photographs;
- images copied from search results or social media;
- copyrighted characters, logos, or artwork without permission;
- STL files derived from an image that cannot be redistributed;
- files containing names, addresses, or other private information.

Every added image should include a short note stating its creator, source, and
license. Every example STL should identify the image and settings used to
generate it.

Gallery images are not examples and have separate rights described in
`public/gallery/README.md`.
